# Design

## Context

Reader 的 `useBottomBarInset`、`toolbarSpace` 和 `resolvedVerticalMargins` 将工具栏测量值传给正文。WebBase 通过 `editor-header-inset` 将外层标题栏高度送入 reader，EPUB viewer 又将正文边距传给引擎。显隐如果改变任一层的占位，会改变 PDF 文字列或 EPUB 分页盒。既有候选的 Chromium 复验也发现，顶层鼠标坐标取整和 iframe 收到的坐标可能落在不同热区。

## Goals / Non-Goals

- 保持同一阅读栏在浮层展开和收起时的正文布局、导航状态与持久化锚点。实际窗口、分栏宽度或字号变化继续按既有重排机制处理。
- 复用相邻可视页命令、阅读范围、失败重试、目录及历史进度。页码只从当前稳定阅读状态派生。

## Decisions

1. **正文布局与浮层命中各用一套几何。** PDF Text 和 EPUB 分页的正文盒仅由单栏容器、稳定 safe area 及现有排版边距决定。标题栏和底栏用各自宿主和阅读栏容器上的定位浮层覆盖正文，从布局流移出。工具栏实际高度（含展开菜单）只用于浮层位置、可用命中带与层叠，标题栏高度同理。适用模式下，`toolbarSpace` 的显隐贡献以及 WebBase 导入的标题栏高度均不得进入正文排版、滚动内边距或 PDF/EPUB 重排依赖。WebBase 的 header 外层容器也不能因切换显隐改变阅读 iframe 的盒。保留物理 safe area、分栏几何和非适用模式的占位规则。显隐只更新浮层、遮罩和命中几何，正文组件、EPUB 章节 iframe、导航及进度订阅保持挂载。
2. **遮罩在展开期间取得正文输入。** 它位于正文（包括 EPUB 章节 iframe 和正文弹层）之上、标题栏和工具栏及其附属菜单之下，范围限定本栏。用同一分类器消费点击和滑动。收起在该输入序列被完整消费后生效，拦住尾随 click，避免底下的内链或高亮收到这一操作。隐藏控件退出命中和焦点顺序。页码独立于遮罩和栏位，使用不可命中的灰色文本，浮层打开时通过浮层层级与右下角控件避让保持可见，其尺寸和位置不参与正文测量。
3. **以按下时的单栏有效阅读区为准。** 在正文可见裁剪盒中排除当前栏位占用的顶部和底部覆盖带，并扣除侧栏及分隔线。记录起点和矩形，在同一区内完成指针序列后按 CSS 像素的起止位移判断。用现有点击手势容差区分轻微移动与拖动，拖动未达阈值或等轴时消费尾随 click。EPUB 按可见 iframe 的实际位置把章节事件坐标转换到同一阅读区域。加载新章节时替换事件订阅。PDF 沿用已有正文节点监听和实时状态引用，避免重渲染期间丢失 pointerdown。
4. **隐藏栏位时先判断所属交互。** 控件及可编辑元素保留原行为，链接及嵌套节点排在叠加高亮之前。命中这些元素的起手以及已被选区、编辑或绘制接管的序列都退出正文分区识别。EPUB 沿用 Foliate 的链接目标与 reader 的高亮 hit test，避免每个监听各自执行一个动作。横滑只从未被消费的主指针序列调用既有 PDF Text turn 或 EPUB turn 命令。只移除按钮界面及其专用输入和占位，保留非按钮导航状态与错误恢复。
5. **按栏、文档会话和模式维护状态。** reader 用每栏会话状态联动底栏和遮罩，宿主按当前编辑器会话及活动栏显示公共标题栏。栏切换只选取状态，换文档或渲染模式重置。旧异步结果不能覆盖当前栏。PDF Layout 恢复自己的既有布局规则。宿主联动可选，无宿主标题栏时独立 reader 的工具栏仍可运作。
6. **页码读取稳定导航状态。** PDF Text 取当前已稳定的原始页号及 PDF 会话全文件 `numPages`，保留隐藏页与范围之外原页的编号。EPUB 可重排章节使用 Foliate 当前稳定章节的分页盒与页位置，排除前后占位页，核对第一与最后真实可视页。封面及固定版式单页直接提供 `1/1`。换章和重排完成后原子更新页序与总数，避免混用不同章节的数据。未就绪且没有对应稳定页码时隐藏指示。

## Risks / Trade-offs

- 真实鼠标和嵌套 iframe 的亚像素偏移可能让门槛测试误判。以接收事件的坐标验证起止点，等号用可整除的正文尺寸，边界两侧分别断言。
- 浮层占位和正文重排可能经标题栏桥间接耦合。用同一文字 Range、正文盒与滚动/分页位移做显示前后比较，并验证展开时浮层确实覆盖正文。
- 同一原始 PDF 页的多次翻页可能显示相同页码。端到端断言同时检查独立正文标记，EPUB 也用真实可视页验证章节计数。

## Migration Plan

reader 构建候选包，WebBase 使用候选包验证，修勾验收后发布 reader，再由 WebBase 使用正式版本复验并合并。回滚正式集成时成对回退 WebBase 联动和正式包依赖，包含根目录与 `webview/` 的锁文件。
