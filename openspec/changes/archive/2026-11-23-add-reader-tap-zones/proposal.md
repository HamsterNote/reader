# Proposal

## Why

HAM-365 的候选版本在验收中出现了栏位切换后正文跳位。根据本轮反馈，阅读页改为用点击和滑动翻页，工具栏临时浮在正文上方，并保留常驻页码。

## What Changes

- **BREAKING** 删除 PDF 纯文字与 EPUB 分页的底部上一页、下一页按钮。保留其可视页导航、边界和并发保护。PDF 布局/预览沿用既有标题栏、工具与滚动行为。EPUB 连续滚动沿用现有范围。
- PDF 纯文字与 EPUB 分页新会话默认隐藏标题栏和底栏。两栏联动，以阅读栏为单位保存显隐，切换活动栏时公共标题栏跟随。翻页保持原显隐状态，切换渲染模式或更换文档后重新初始化，回到适用模式时为隐藏。
- 栏位隐藏时，点正文上四分之一、下四分之一或中间一半的中间三分之一显示栏位。中间一半的左、右三分之一分别上一页、下一页。横滑右到左下一页、左到右上一页，门槛为单栏有效阅读区宽度的三分之一。上下滑都切换栏位，门槛为高度的三分之一。门槛包含等号，横竖取位移绝对值较大的轴。
- 栏位悬浮覆盖正文。展开时有效阅读区里的点击、达阈值横滑或竖滑只收起栏位。未达阈值的拖动保持展开。栏位自身及其菜单仍可操作。收起时，正文链接优先于同坐标高亮，高亮优先于分区动作，按钮等控件保留自己的操作。在交互目标上起手或被选择、绘制等手势接管的拖动不触发分区或翻页。
- 两种适用模式正文右下角常驻灰色 `当前/总数`。PDF 用当前原始 PDF 页号和文件总页数，同一原页的可视页之间数字保持。EPUB 用当前章节内从 1 开始的可视页序号和该章的可视页总数，换章时以目标章重新计数。封面和固定版式单页显示 `1/1`。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `pdfjs-web-reader` 修订 PDF Text 翻页输入、悬浮显隐和原文页码口径。
- `epub-web-reader` 修订 EPUB 分页翻页输入、悬浮显隐和章节内可视页码口径。

## Impact

- reader 的 `src/components/Reader.tsx` 渲染 `src/components/Reader/DefaultBottomBar.tsx`，经 `ToolbarShell` 显示工具栏。目录和渲染模式分别经 `onOutlineToggle`、`onRenderModeChange` 回接 Reader 状态。
- 包仓基线的底部控件 `src/components/reading/ViewportPaginationControls.tsx` 通过 `fire(direction)` 回调上一页和下一页。PDF Text 在 `IntermediateDocumentTextViewer.tsx` 经 `PdfTextReadingControls.tsx` 调用 `pdfPagination.turn`，EPUB 在 `EngineDocumentViewer.tsx` 经 `turnEpub` 调用引擎 `previousPage/nextPage`。移除的是按钮界面及专用占位，导航命令和 PDF 失败重试继续使用。
- EPUB 章节内链与高亮分别经过 `vendor/foliate-js/view.js` 及 `src/epub/foliateEpubEngine.ts` 的章节 click 与 `overlayer.hitTest`。WebBase 的 `ReaderEditorPane.tsx` 接入 Reader，`EditorSessionHeader.web.tsx` 渲染公共标题栏，`webview-shell.web.tsx` 与 `App.tsx` 通过 `editor-header-inset` 同步顶部占位。适用模式需把该占位与浮层显隐解耦。

## 交付顺序与依赖

1. **reader 实现**。基于已有候选的验证经验修订交互，构建本地候选包。
2. **WebBase 本地验证**。安装第 1 步的候选包并执行下列 Chromium 用例。记录候选版本、包校验值和结果，交修勾验收。
3. **发布 reader**。第 2 步及人类验收通过后，按既有流程发布 reader，确认正式版本可安装。
4. **正式集成 WebBase**。升级根目录和 `webview/` 的依赖与锁文件，使用正式包重跑验收。reader 正式版本发布且可安装后才可合并使用方 PR。

## 冒烟 / 自测用例

开发时验收为 Web-only。复用 HAM-343 的 `webview/e2e-app/local-test-imports.spec.ts`，通过 `filechooser.setFiles` 导入带独立文字标记的多页 PDF 与多章 EPUB。PDF 样本包含可重排为多个可视页的长原页，EPUB 包含两个可视页数不同的章节及重叠高亮的内链。正文坐标和指针回执取自对应 frame，映射到顶层页面发出鼠标输入。每次滑动使用 `mouse.move/down/move/up`，按实际接收的 CSS 像素核对位移。等号场景设置尺寸能被 3 整除的有效阅读区。导航完成后断言目标文字可见，静止场景同时检查原文字和页码。

| 用例 | Chromium 可观测断言 |
| --- | --- |
| 默认状态与点击分区 | 两种适用模式打开后标题栏、工具栏均隐藏，DOM 中不存在底部翻页按钮，灰色页码可见。分别测纵向 1/4、3/4 与中段横向 1/3、2/3 的分界及两侧。上、下、中间三分之一只打开栏位，中段左右只向对应方向前进或后退一个可视页。 |
| 横滑与竖滑门槛 | 两种格式分别测双方向的门槛 `1/3 - 1px`、`1/3`、`1/3 + 1px`。门槛下不翻页或切栏位，且不退化为点击。横向到门槛时按方向只移动一页，竖向到门槛时只显隐。等轴斜滑与取消手势保持正文和显隐。 |
| 展开期间关闭优先 | 打开栏位后，在中段翻页区、可交互链接/高亮的位置分别真实点击，只隐藏栏位。横滑、竖滑达门槛也只隐藏，差 1px 的拖动保持展开。确认没有链接跳转、菜单或翻页，点击栏位工具本身则只执行该工具动作。 |
| 正文的交互优先级 | 栏位隐藏时点击 EPUB 高亮所覆盖的内链子节点，只出现链接目标，`.hsn-selection-popover` 不出现。分别点独立高亮与正文按钮验证各自响应。从链接、高亮或控件起手做过门槛拖动，以及拖选正文，断言无分区翻页、无切换和无尾随点击的重复动作。 |
| 正文无位移 | 在单栏宽屏、窄屏及双栏活动栏的非初始阅读位置，打开再关闭栏位。逐次比较正文盒、同一文字 Range 的位置及尺寸、滚动偏移或分页平移和页码，坐标差允许不超过 0.5 CSS px。展开的底栏与正文盒相交，页码两态都可见。 |
| 页码口径 | PDF 从 `1/N` 在同原页翻下一个视口仍为 `1/N`，跨到原页 2 为 `2/N`，隐藏页或页范围限制时保持原编号与全文分母。EPUB 同章递增，换章首屏显示 `1/目标章可视页数`，反向回到上一章末页，封面和固定版式单页为 `1/1`。字号或视口变化后 EPUB 页码与实际重排一致，单纯显隐保持原值。 |
| 双栏、边界和模式隔离 | 使用同一位移，命中窄栏的 1/3 门槛而低于宽栏门槛，只有窄栏翻页。切换活动栏保留各栏显隐，公共标题栏跟随，另一栏文字不动。PDF Text 切到 Layout 后滑动不触发新增翻页且滚轮正常，切回 Text 后默认隐藏。两种适用格式的首尾向外和受控忙碌期间重复滑动不造成额外移动。 |
